# Resources

Local-only assets (not all belong in git).

| Subdir | Purpose |
|--------|---------|
| `papers/` | PDFs you downloaded (prefer links + notes in `courses/*/readings/` instead of committing binaries) |
| `blogs/` | Saved HTML/PDF exports |
| `tools/` | Helper scripts (also see `projects/`) |
| `datasets/` | Small public tensors or fixtures; use `.gitignore` for large files |

See [CONTRIBUTING.md](../CONTRIBUTING.md) for file size and licensing norms.
